## Что сделано

В MR1 была реализована загрузка словаря из файла, дальше из случайно выбирается слово и она при одних и тех же данный всегда одно. Есть ядро программы, где обрабатывается загадное слово путем есть лимит попыток и история, статус. Также реализован один соственный тест.

## Требования MR1

- [+] Словарь: минимум 50 слов по 5 букв
- [+] Случайный выбор слова с фиксируемым `seed`
- [+] Модель сессии: `answer`, `maxAttempts`, `attemptsUsed`, `attemptsHistory`, `status`
- [+] Статусы `IN_PROGRESS | WIN | LOSE`
- [+] `startGame(dictionary, maxAttempts, seed) -> GameSession`

### Инварианты

- [+] Слово из словаря и ровно 5 букв
- [+] `maxAttempts > 0`
- [+] Завершённая игра не принимает новые попытки

## Обязательные тесты

С реализованных тестов снят `@Disabled`:

- [+] `mandatory/mr1/DictionaryTest` — размер словаря, длина слов, пустой словарь
- [+] `mandatory/mr1/SeedTest` — одинаковый seed даёт одинаковое слово
