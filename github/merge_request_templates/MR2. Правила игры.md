## Что сделано

Реализована полная логика игры «5 букв» . Добавлен класс  для возврата результата проверки попытки. Создана 
валидации - проверка длины и диапазона 
символов выполняется посимвольно.

Также есть двуэтапный алгоритм окраски букв по совпадению и добавлен метод для работы тестов


## Требования MR2

- [+] `applyGuess(session, guess) -> GuessResult`
- [+] Ввод без учёта регистра, только буквы, ровно 5, слово есть в словаре
- [+] **Некорректный ввод не тратит попытку**
- [+] Статусы букв `✅ 🟡 ❌`
- [+] Определение победы и поражения
- [+] Логика проверки отделена от консольного ввода-вывода

### Повторяющиеся буквы

Каждая буква ответа расходуется один раз: сначала отмечаются все `✅`,
затем оставшимися буквами закрываются `🟡`.

- [+] `сорок` / `оооом` даёт `🟡❌❌✅❌`, а не `🟡🟡🟡✅❌`

## Обязательные тесты

С реализованных тестов снят `@Disabled`:

- [+] `mandatory/mr2/GuessValidationTest` — длина, не-буквы, слово вне словаря, попытка не тратится
- [+] `mandatory/mr2/LetterMatchingTest` — базовый кейс и обязательный `сорок / оооом`
- [+] `mandatory/mr2/GameOutcomeTest` — WIN, LOSE, показ ответа
